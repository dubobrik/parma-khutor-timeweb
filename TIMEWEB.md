# Парма Хутор — перенос на Timeweb

Подготовленная версия из Lovable, commit 33d7e5e296d7ba047fd525a93e08a811cfa08352.

## Размещение через GitHub
Содержимое папки parma-timeweb загрузить в корень отдельного репозитория. Не заменять репозиторий Руслана. Не отправлять изменения в связанную с Lovable ветку без проверки синхронизации.

Timeweb App Platform: Frontend → Другой; Node.js 24.
Команда сборки: npm run build
Директория сборки: dist/client
Путь проекта: корень репозитория.
Для воспроизводимой локальной установки: npm ci
API-ключи и база данных не требуются. Стоимость нового приложения согласовать до создания.

Документация: https://timeweb.cloud/docs/apps/deploying-frontend-apps
Статическая сборка: https://tanstack.com/start/latest/docs/framework/react/guide/static-prerendering

## Изменения
В политике заменён абзац о будущем подключении Telegram на описание действующего контакта @andrey_olenevka; обновлены два описания страницы в метаданных. Остальные тексты, дизайн, контакты и группировка фото сохранены.
Настройка сборки Lovable заменена стандартными плагинами Vite и TanStack Start; добавлена предварительная сборка трёх страниц. Убраны зависимости от конфигурации Lovable и Nitro. Добавлен package-lock.json; используется npm, исходный bun.lock сохранён в резерве.
Все 102 изображения размещены в public по прежним адресам /__l5e/assets-v1/... — это теперь обычные локальные файлы, обращения к Lovable для их выдачи не нужны.

## Проверки и ограничения
Сборка и TypeScript прошли. Все 102 изображения проверены; внутренние ссылки на ресурсы трёх страниц разрешаются в локальные файлы. Локальная HTTP-проверка выполнена для /, /privacy/, /consent/ и favicon.ico.
Визуальная проверка и клики в браузере остаются обязательным этапом на техническом адресе Timeweb: локальный адрес недоступен встроенному браузеру.
Внешние Google Fonts сохранены, поскольку замена шрифтов не согласована.
В резервной версии Lovable ничего не изменено. Публикация и домен не подключались.

## Следующие проверки на Timeweb
Открыть /privacy и /consent напрямую и после перезагрузки. Проверить телефон, Telegram, мобильное меню, все галереи, отсутствие горизонтальной прокрутки. После проверки подключить домен.
